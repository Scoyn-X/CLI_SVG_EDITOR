# 需求与设计决策

版本：v0.3，2026-10-12。来源为 [课程需求](../phase_cli_1.md)；本文件解释未定义处，不修改原文。

状态定义：**明确**来自题目明文；**暂定**是为继续实现形成的工程基线，未经教师确认，遇到补充要求可修订；**开放**尚未确定支持范围，需在相关实现阶段前处理。暂定设计不应在课程报告中冒充明文要求。

## D01：类型、id 与根画布

状态：明确为主；根画布处理为暂定。来源：§2、§3、§4.1。

- 内置类型仅 rect、circle、ellipse、line、text、g。create box 和其他类型使用规定未知类型错误。
- 图形及 g 的 id 非空、全局唯一、大小写敏感；命令通过 id 定位。暂定拒绝 id 中的空白及 XML 非法字符，不额外强制 ASCII 或特定前缀。
- svg 根画布由文档管理，不视为普通 g，不生成可被 delete/group/ungroup 定位的图形 id。
- 导入先收集全部已有 id 并拒绝重复，再按文档前序顺序给缺 id 元素分配标签名加最小可用正整数。计数只属于候选导入状态。
- 警告例：`warning: assigned id rect1 to unnamed <rect>`。候选导入失败时不发布补 id 警告，也不改变现文档。

## D02：几何、属性与样式缺省

状态：明确 + 暂定校验。来源：§2、§3、§4.1—§4.2。

- move 修改增量坐标。scale 正数因子乘到全部受支持几何属性，容器递归处理；不以中心缩放，不自动修改 stroke-width。
- 各形状 set 白名单严格按 §4.1；id、transform、font-size、label 都不在第一阶段 set 白名单。普通 g 只有公共样式属性，无 x/y 或 text 属性。
- 样式缺省与显式设置分别保存。普通 g 的公共样式设置暂定只改变 g 自身，子节点通过 SVG 继承获得效果，不覆写子节点的显式值。
- 暂定：坐标可为负；图形宽高、半径和 stroke-width 非负，允许零；画布宽高严格正数；所有数值和运算结果必须有限，拒绝 NaN/Infinity 和溢出。
- 暂定：数字采用完整 token 校验，接受十进制与科学计数法，拒绝 `10abc`、十六进制和命令参数中的 `10px`。外部 SVG 单位另见 D09。
- 暂定：输出数字保留可往返的精度，负零显示为 0，不固定截断小数位。text 缩放本阶段改变 x/y；扩展字体属性的导入与缩放语义见 D09，不作无依据推断。

## D03：group 的位置与相对顺序

状态：部分明确，跨父级位置暂定。来源：§3、§4.2。

明确：所有目标必须存在，新 id 必须唯一；不能同时收编某容器及其子孙；保留图形的相对顺序。

暂定算法：

1. 先验证全部目标，拒绝重复 id；整个过程不修改原文档。
2. 取所有目标原父级的最低共同容器；根画布也参与父级计算。
3. 按修改前文档的前序顺序排列目标，不按命令参数顺序排列。
4. 新 g 放在共同父级下，插入原来包含目标的直接分支中最靠前的位置。
5. 从各自原父级摘下目标，按步骤 3 的顺序放入新 g；未选图形的相对顺序保持。

同父级例：原 `[a, b, c, d]`，`group pair c a` 后为 `[pair(a,c), b, d]`。参数倒序不改变 a、c 的原相对顺序。

跨父级例：根为 `[left(a,x), middle, right(b,y)]`，`group pair b a` 后为 `[pair(a,b), left(x), middle, right(y)]`。新组挂在根，原空容器仍保留。

该选择定义结构语义，不保证重组前后像素外观不变：样式继承与穿插遮挡可能变化。本阶段暂不物化继承样式，也不加入复杂坐标补偿；如果导入支持变换，必须重新核对重组语义（D09）。

阶段 5 单元 A 已按此算法实现，领域、历史和真实 CLI 回放验证同级/跨父/深层共同父级、原顺序、单目标和祖先冲突。构造/复制新组及检查与未选节点的 id 冲突均在摘除旧节点前完成。空目标/重复目标暂定补充 `group requires at least one shape` / `duplicate group target: <id>`；CLI 空目标先报语法错误。位置算法仍未经教师确认，实际落点见 [tree-editing.md](tree-editing.md)。

## D04：addto、ungroup 与 z-order

状态：明确为主，边界为暂定。来源：§3、§4.2；z-order 按 SVG 绘制语义。

- addto 的目标具有容器资格；当前是 g。不得把节点放入自身或子孙。移入后为最后一个子节点；若原已在该父级，暂定移到末尾。
- ungroup 对根级 g 报 `error: cannot ungroup top-level container: <id>`。可解散的嵌套 g 删除自身，子节点保持顺序替换它在父级的位置；空 g 解散后不留下占位节点。
- front 移到同级列表末尾（最后绘制，视觉最前），back 移到列表开头；不越级，不改变归属。
- 暂定：group 至少需要一个目标；输入为零个目标时报语法错误。一目标组仍有意义，不额外要求两个。
- 未来复合容器的“可容纳”与“可解散”是独立能力；当前不注册复合类型。

阶段 5 单元 A 已实现 addto/ungroup：Shape.canUngroup 与容器协作能力分开；先判断容器、可解散能力，再判根级限制。循环归属暂定错误为 `cannot add a shape into itself or its descendant: <id>`；源/目标同时无效时先报源节点错误。解组/归属同样不物化继承样式；显式属性不变不等于视觉不变。

单元 B 已实现 delete/front/back 与完整快照恢复：front 为同级末尾、back 为同级开头；节点身份/父级不变时不重建索引。边界成功仍按 D05 入栈；删除容器一个单元恢复全部后代、id/父级/位置和缺省属性。摘要中前后顺序用 moved to front/back、undo 用 order restored，题目未规定这些措辞，作为可修订的工程选择。

参考：[SVG 2 绘制模型](https://www.w3.org/TR/SVG2/render.html)。

## D05：历史状态机及无变化命令

状态：明确 + 暂定旧历史处理。来源：§3、§4.3。

| 当前状态/操作 | 文档及历史结果 |
| --- | --- |
| 尚无文档 | 暂定除 init/read 外的命令报题目无文档错误；help 的例外尚未确认 |
| init/read/save/canvas 修改成功 | 进入屏障状态，undo/redo 均报 `error: undo not allowed after io command` |
| 屏障后成功编辑 | 建立新历史并解禁 undo/redo |
| undo 后新编辑成功 | 添加新历史条目并清空 redo |
| 任意失败命令 | 文档、路径、计数及两栈保持原状 |
| tree/show/help/canvas 查询 | 不入栈，不改变屏障或 redo |

暂定：成功建立屏障时清空此前的 undo/redo，避免以后跨越新文档或尺寸修改。屏障状态仍显式保存，所以不能用“栈空”代替指定错误。

暂定：成功编辑即使数值没变化（move 0 0、scale 1、已在最前的 front）也形成一个历史单元，清空 redo 并解禁屏障，与“一条编辑命令一个单元”一致。屏障后 canvas 参数与旧值相同仍属于文档修改命令。

暂定空历史错误：`error: nothing to undo` / `error: nothing to redo`。未建文档时优先无文档错误，有屏障时优先屏障错误。

阶段 4 已按本基线实现并测试：显式屏障清空两栈，成功编辑（包括无变化）入一个单元并解禁；canvas 查询和当前 help 保持两栈/屏障。阶段 5 已补 group/delete/ungroup/addto/front/back 的单条粒度、完整结构恢复及失败保留 redo；read/save 的真实 IO 仍待阶段 6。清除旧历史、无变化编辑及空栈错误仍是工程暂定规则，非教师确认。

## D06：路径和保存

状态：明确 + 暂定路径生命周期。来源：§3、§4.2。

- 无参数 save 使用成功 read 时的路径，不把另存路径擅自解释为“读入时的路径”。
- 暂定：init 清除读入路径；read 成功才替换读入路径；显式 `save new.svg` 不改变读入路径。
- 因此 init 后显式保存仍可成功，但之后无参数 save 暂定报 `error: no source path. specify a file`；该新增错误不是题目原文。
- 暂定：相对路径按启动 CLI 的工作目录解析；路径参数支持双引号。会话保存解析后的绝对路径，避免后续工作目录变化。
- 文件读写错误使用题目指定 `cannot read file` / `cannot write file`。暂定反馈优先展示用户传入路径，不泄漏底层堆栈。
- 写入先在目标目录生成临时文件，再采用平台支持的替换方式。不得先删除旧文件；失败清理本次临时文件，原会话/历史保持。阶段 6 验证 Windows 下已有目标的替换行为，不提前宣称跨平台原子性。

## D07：CLI 语法与输出

状态：明确 + 暂定未定义语法。来源：§2、§3、§5。

- 提示符 `svg>`，逐行 REPL。暂定空行跳过，首个非空白字符为 # 的整行作为注释；没有行内注释。颜色参数 #ffffff 按原样保留。
- 双引号保留空格和空字符串，token 携带 quoted 标记。仅识别 create 末尾的未加引号 `in` 及其一个目标 token，正文 `"in"` 不能被移除。
- 暂定支持引号内的反斜杠转义双引号和反斜杠，其他反斜杠按原样保留（如 Windows 路径）；拒绝未闭合引号，不执行 shell 展开/插值。
- 暂定 init 接受零、一、两个数值参数：0 为 800×600；1 只指定宽，高为 600。canvas 接受 0/1/2：0 查询，1 修改宽并保持现高，2 修改两者。
- 暂定校验顺序：分词 → 命令名/结构语法 → 文档状态 → 类型/schema 和标量 → id/容器/祖先关系 → 候选执行。每条失败只发布一个 error，错误优先级在测试中固定。
- 成功编辑回显摘要；tree 内联几何属性，show 显示 parent 与属性。未指定错误可补充单行说明，已指定文字必须严格匹配。
- 暂定 show 根级图形的 parent 显示为 svg。统计元素数包含全部叶子和 g，不包含 svg 根；保存本身不新增图形。
- 启动文案遵循题目示例。EOF 正常退出；不新增未要求的 exit 命令。具体退出码与交互/管道提示符行为在 CLI 实现阶段明确。

## D08：失败原子性与恢复

状态：明确约束 + 工程设计选择。来源：§2、§4.3。

阶段 3 的实际基础：ShapeTree 附着前验证整个子树，持有来源的独立副本；Group 几何修改先准备全部子孙，再应用已验证值。SvgDocument.clone 经具体类多态复制并重建索引，样式值不可变、视图冻结。相关领域测试已通过，详见 [domain-model.md](domain-model.md)。阶段 4 已实现下述 Command/历史/会话规则，实际职责与取舍见 [command-history.md](command-history.md)。

每次编辑在候选文档上运行，成功才发布候选和单个历史条目；父级、id 索引及计数均随候选状态管理。失败创建、分组或读入不能消耗可观察的 id 分配状态。

阶段 4 发布前额外复制候选并准备独立前/后快照，准备失败仍保留全部会话状态，命令保留候选引用不能修改已发布文档。undo/redo 先准备恢复副本再迁移栈，redo 不重跑命令/工厂。编辑仅改变文档，路径在文档发布边界管理；同步执行锁防止重入，未来异步 IO 继续串行。

undo/redo 使用独立的领域对象副本，不共享可写快照；恢复包括明确缺省的属性、所有节点、父级、顺序和子类型。SVG 文件会省略内部状态，不能用作 Memento。未来提供者构造的子树必须完整验证后整体附着。

## D09：SVG 导入范围

状态：基本范围明确；扩展范围开放，最迟阶段 6 前定稿。

当前明确支持的最小范围：标准 SVG 命名空间、svg 根尺寸、六种标签、嵌套 g、规定几何/公共样式和纯文本 text；缺 id 自动补。重复 id、畸形 XML 及不合法领域值使 read 失败并保留旧状态。

暂定基本约定：数字或 px 单位的根宽高可转换为画布尺寸；几何采用无单位数字；省略的几何属性依 SVG 对应默认值处理；根宽高缺省/百分比需先确认，不自行套用浏览器布局尺寸。XML 声明、注释及格式空白不作为可编辑节点或元素计数。

开放事项：

| 项目 | 需要决定的内容 | 当前底线 |
| --- | --- | --- |
| transform | 支持 translate/scale、保留变换或拒绝；text、stroke、重组的视觉一致性 | 背景包含变换示例，不能直接宣称它是无关功能；禁止静默去掉变换 |
| viewBox | 非 0 0 w h 坐标系保留、归一化或拒绝 | 不能重写为默认值后声称往返无损 |
| font-size、text-anchor 等 | 受控保留属性集合及其缩放语义 | 导入范围与 set 白名单分别定义，不能把“不能 set”等同“可以丢弃” |
| 未知标签、style/CSS、text 子节点 | 严格拒绝或保留方案 | 未实现支持时显式拒绝，不静默删除 |
| data-kind | 已知插件恢复与未知类型降级普通 g 的未来路径 | 预留工厂位置，不实现 box；保留标记策略与额外属性一起确认 |
| 外部资源和实体 | XML 库解析设置及引用处理 | 不加载外部实体/资源；不以导入操作触发网络请求 |

实现前选定 XML 库并核对实际默认行为、错误和安全配置。当前没有选定依赖版本，也没有宣称已完成完整 SVG 往返。
